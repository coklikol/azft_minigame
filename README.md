# 🎨 Угадай Картинку

Игра для двоих: загадываешь картинку, соперник задаёт вопросы и исключает варианты.

## ⚠️ Почему друг не видел комнату (важно!)

Раньше игра хранила комнаты только в **localStorage** и общалась через **BroadcastChannel**.
Оба этих механизма работают **только внутри одного браузера на одном устройстве**.
Cloudflare Pages отдаёт один и тот же файл всем, но данные при этом остаются у каждого в своём браузере —
поэтому комната, созданная у тебя, у друга не появлялась.

## ✅ Как теперь играть с другом на расстоянии

Комнаты, игроки, ходы и чат синхронизируются через маленький сервер — **Cloudflare Worker** (бесплатно).

### 1. Задеплойте Worker (один раз, ~5 минут)

```bash
npm install -g wrangler
wrangler login
cd cloudflare-worker
wrangler kv namespace create SYNC     # скопируйте id из вывода
# вставьте id в wrangler.toml (поле id = "...")
wrangler deploy
```

После деплоя получите адрес вида `https://guess-sync.<ваше-имя>.workers.dev`.

### 2. Укажите адрес сервера в игре

Откройте `index.html`, найдите строку:

```js
const SYNC_SERVER_URL = 'https://REPLACE-WITH-YOUR-WORKER-URL';
```

и вставьте туда URL воркера. Залейте обновлённый `index.html` на Cloudflare Pages как обычно.

> Быстрая проверка без правки файла: можно открыть игру с параметром
> `https://ваш-сайт.pages.dev/?server=https://guess-sync.xxx.workers.dev`

### 3. Играйте

- Вы и друг открываете сайт **на разных устройствах**, вводите **разные ники**.
- Создаёте комнату → код появится у друга в списке «Активные комнаты» в течение ~2 секунд
  (или он может ввести код вручную; префикс `R-` вводить не обязательно).
- Обновления приходят автоматически, перезагружать страницу не нужно.

## Что изменилось в коде (`index.html`)

- Добавлен сетевой слой синхронизации: `/api/room/<код>`, `/api/chat/<код>`, `/api/events?since=...`
  (поллинг каждые 1.5 сек + мгновенный опрос при создании/входе в комнату).
- `localStorage` теперь работает как кэш: при временном отсутствии сети игра продолжает работать локально,
  а неотправленные изменения накапливаются в очереди и досылаются при появлении связи.
- Коды новых сетевых комнат имеют префикс `R-`; старые локальные комнаты продолжают работать.
- В лобби показывается статус соединения с сервером синхронизации, на экране входа — подсказка,
  если сервер не настроен.
- Серверная часть — в папке `cloudflare-worker/` (`worker.js` + `wrangler.toml`).

## Панель администратора

Категории и картинки по-прежнему хранятся локально в браузере (localStorage) —
у каждого игрока своя база картинок. Чтобы у друга были те же категории/картинки,
добавьте одинаковые ссылки-картинки в админке на обоих устройствах
(демо-категории с случайными картинками подгружаются автоматически).
